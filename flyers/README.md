# Flyers

Put **real, approved flyers** in this folder (or a subfolder) and add their paths to `specials.json`.

Rules:

- Portrait only, about 3:4 (1080 × 1440 recommended).
- At least 800 px wide.
- WebP, JPG or PNG.
- Under 200 KB.
- The start and end dates printed on the flyer must match the entry in `specials.json`.
- The business must have approved the flyer before it is merged.
- Each site owner must approve appearing in `showOn`.

`_test/` contains two sample images. They are only for automated tests and the local demo. The validation script refuses to publish anything from `flyers/_test/`.
